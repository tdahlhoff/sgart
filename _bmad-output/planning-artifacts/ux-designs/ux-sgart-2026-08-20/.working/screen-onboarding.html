Erste Schritte — der Admin-Weg (Werner)

The one flow where the creator/Admin burden lands on a non-expert older user with no power user to help. So it's a gentle, one-step-at-a-time wizard: plain language, reassurance that nothing is permanent, big targets, and a way to skip. Sequence: create household → add stores (with an advisory chain suggestion) → invite someone.

Design decisions: guided one-step-at-a-time wizard with a visible progress bar (Werner never feels lost) · plain-language German, encouraging microcopy, reassurance that changes aren't permanent (reduces "break it" fear) · every step skippable where the spec allows (stores & invite optional) · client-side chain suggestion is advisory, confirm/change/clear, never forced (CAP-3) · 52–54px controls, text-only buttons · privacy stated up front · "Auf Einladung warten" is the recipient path (Rita); "Später einladen" proves solo is first-class (Jonas).
